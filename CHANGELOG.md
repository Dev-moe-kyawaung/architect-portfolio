## [1.0.0] - 2026-08-06

### Added
- Initial release of the Senior Mobile/Android Architect portfolio.
- Dark-glass theme with CSS custom properties and glassmorphism panels.
- Hero section with 3D floating tech cards and mouse-parallax tilt.
- Canvas-based particle background with proximity-linked connections.
- Animated Skills Matrix (canvas radar chart + progress bars).
- Android Roadmap timeline (12 years, four eras).
- Compose UI Gallery with hover-tilt cards.
- Architecture Lab layered diagram (Presentation / Domain / Data / Platform).
- Performance Benchmarks with animated sparkline mini-charts.
- CI/CD pipeline visualization (Commit → Play Store).
- Project Showcase grid.
- GitHub Network stats and Certifications grid.
- Testimonials section and Contact CTA.
- Bilingual English ⇄ Burmese (Myanmar) toggle across all copy.
- Scroll-triggered reveal animations via IntersectionObserver.
- GitHub Actions deploy workflow for GitHub Pages.
- GitLab CI configuration for GitLab Pages.
- Repository documentation: README, CONTRIBUTING, SECURITY, LICENSE.
